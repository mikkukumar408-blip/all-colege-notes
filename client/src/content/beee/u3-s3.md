### 1. Rectification Circuits & Performance Analysis

A **rectifier** converts bidirectional alternating voltage (AC) into pulsating unidirectional direct voltage (DC).

#### Performance Metrics Catalog:
- **Rectification Efficiency ($\eta$):** $\eta = \frac{P_{dc}}{P_{ac}} = \frac{I_{dc}^2 R_L}{I_{rms}^2 (R_f + R_L)}$.
- **Ripple Factor ($\gamma$):** Ratio of RMS AC component to DC component:
  $$\mathbf{\gamma = \frac{V_{ac,rms}}{V_{dc}} = \sqrt{\left(\frac{V_{rms}}{V_{dc}}\right)^2 - 1}}$$
- **Peak Inverse Voltage (PIV):** Maximum reverse voltage across a non-conducting diode.

### 2. Mathematical Comparison of the Three Standard Rectifier Topologies

| Metric | Half-Wave Rectifier | Center-Tapped Full-Wave | Full-Wave Bridge Rectifier |
| :--- | :--- | :--- | :--- |
| **Diode Count** | **1** | **2** | **4** |
| **Center-Tap Transformer Needed?** | No | **Yes (Expensive, Bulky)** | **No (Standard transformer)** |
| **Peak Inverse Voltage (PIV)** | $V_m$ | $\mathbf{2 V_m}$ | $\mathbf{V_m}$ *(Economical!)* |
| **DC Output Voltage ($V_{dc}$)** | $\frac{V_m}{\pi} \approx 0.318 V_m$ | $\frac{2 V_m}{\pi} \approx 0.637 V_m$ | $\mathbf{\frac{2 V_m}{\pi} \approx 0.637 V_m}$ |
| **RMS Output Voltage ($V_{rms}$)** | $\frac{V_m}{2} = 0.50 V_m$ | $\frac{V_m}{\sqrt{2}} \approx 0.707 V_m$ | $\mathbf{\frac{V_m}{\sqrt{2}} \approx 0.707 V_m}$ |
| **Max Efficiency ($\eta_{\max}$)** | $\mathbf{40.6\%}$ | $\mathbf{81.2\%}$ | $\mathbf{81.2\%}$ |
| **Ripple Factor ($\gamma$)** | $\mathbf{1.21}$ | $\mathbf{0.482}$ | $\mathbf{0.482}$ |
| **Fundamental Ripple Frequency** | $f$ ($50~\text{Hz}$) | $2f$ ($100~\text{Hz}$) | $\mathbf{2f}$ ($100~\text{Hz}$, easier to filter!) |

### 3. Waveform Shapers: Clippers, Clampers & Filters

1. **Clippers (Limiters):** Non-linear wave-shaping networks that remove a portion of an input signal above or below a specified reference voltage without distorting the remaining waveform.
2. **Clampers (DC Restorers):** Networks comprising a diode, resistor, and capacitor that clamp either the positive or negative peak of an input waveform to a specified DC reference level, preserving the original peak-to-peak amplitude $2V_m$.
3. **Capacitor Filter ($C$-Filter):** A large capacitor placed in parallel with load resistor $R_L$ charges to peak $V_m$ and slowly discharges through $R_L$ with time constant $\tau = R_L C \gg T$:
   $$\mathbf{V_{r(p-p)} = \frac{I_{dc}}{2 f C}},      \mathbf{\gamma = \frac{1}{4\sqrt{3} f C R_L}}$$

For a bridge rectifier:
$\text{PIV} = V_m = \mathbf{16.97~\text{Volts}}$

**University Question (8 Marks):**
A full-wave rectifier delivers power to a 500~\Omega load resistor from a secondary voltage of v(t) = 50 \sin(314t). Each diode has forward resistance Rf = 20~\Omega.
Calculate: (1) DC load current Idc, (2) Rectification efficiency η, (3) Ripple factor γ.

---

**Step 1 🚀: DC Load Current**
Iₘ = (Vₘ / Rf + RL) = \frac{50}{20 + 500} = \frac{50}{520} = 0.09615,A
Idc = (2 Iₘ / π) = (2 × 0.09615 / π) = 0.0612,A = 61.2,\text(mA)

**Step 2 ⚡: Rectification Efficiency η**
η = (Pdc / Pₐc) = (0.812 / 1 + (Rf / RL)) = (0.812 / 1 + \frac{20}{500}) = (0.812 / 1.04) = 78.08%

**Step 3 🎯: Ripple Factor**
$$\gamma = \sqrt{\left(\frac{I_{\text{rms}}}{I_{\text{dc}}}\right)^2 - 1} = \sqrt{(1.11)^2 - 1} = 0.482$$


🎯 $I_{dc} = 61.2~\text{mA}$ | Efficiency $\eta = 78.08%$ | Ripple Factor $\gamma = 0.482$.




**University Question (10 Marks):**
A full-wave bridge rectifier is supplied by a 50,Hz AC source with peak voltage Vₘ = 24,V. The DC load draws Idc = 200,mA.
Design a shunt capacitor filter such that the peak-to-peak ripple voltage Vᵣ does not exceed 1.0,V. Also determine the resulting ripple factor γ.

---

**Step 1 🚀: Capacitor Filter Sizing Formula**
For full-wave rectifier, ripple frequency is 2f = 2 × 50 = 100,Hz.
Vᵣ₍ₚ₋ₚ₎ = \frac{Idc}{2 f C}
1.0 = (0.20 / 2(50) C) = (0.20 / 100 C) ⇒ C = (0.20 / 100) = 2.0 × 10⁻³,F ⁼ ²⁰⁰⁰,μF

**Step 2 ⚡: DC Output Voltage with Filter**
Vdc = Vₘ - (Vᵣ₍ₚ₋ₚ₎ / 2) = 24 - (1.0 / 2) = 23.5,Volts

**Step 3 🎯: Ripple Factor γ**
γ = (Vᵣ₍ᵣₘₛ₎ / Vdc) = (Vᵣ₍ₚ₋ₚ₎ / 2√(3) · Vdc) = (1.0 / 2√(3) × 23.5) = (1.0 / 81.41) = 0.0123 = 1.23%


🎯 Filter Capacitor $C = 2000,μ\text{F}$ | Output $V_{dc} = 23.5~\text{V}$ | Ripple Factor $\gamma = 1.23%$ (Ultra-smooth DC).
