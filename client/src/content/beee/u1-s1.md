### 1. Fundamental Principles of Circuit Theory vs Field Theory

Electrical engineering operates in two complementary realms: Maxwell's Electromagnetic Field Theory and Lumped Circuit Theory.
> 🟢 **The Lumped Circuit Assumption:** Electric circuit theory is an idealized approximation of Maxwell's equations, valid when the physical dimension of the network $d$ is much smaller than the electromagnetic wavelength $λ = c / f$:
> $$\mathbf{d \ll λ = \frac{c}{f}}$$
> At power frequencies ($50~\text{Hz}$), $λ = \frac{3 \times 10^8}{50} = 6000~\text{km}$. Since bench circuits and domestic appliances are meters long, electromagnetic propagation delays are negligible.

#### Charge, Current & Energy Relations:
1. **Electric Current ($i(t)$):** The time rate of transport of electric charge past a specified cross-section:
   $$\mathbf{i(t) = \frac{dq(t)}{dt}} \iff q(t) = \int_{-∞}^t i(\tau),d\tau    [\text{Coulombs, } \text{C}]$$
2. **Electric Potential / Voltage ($v(t)$):** The work required to move a unit positive test charge through an electric field between two points:
   $$\mathbf{v(t) = \frac{dw(t)}{dq}}    [\text{Joules/Coulomb} = \text{Volts, } \text{V}]$$
3. **Instantaneous Electric Power ($p(t)$):** By the differential chain rule:
   $$\mathbf{p(t) = \frac{dw}{dt} = \left(\frac{dw}{dq}\right)\left(\frac{dq}{dt}\right) = v(t) · i(t)}    [\text{Watts, } \text{W}]$$
   - **Passive Sign Convention:** If reference current enters the positive terminal ($+$), $p(t) > 0 ⇒$ **element absorbs / consumes energy**. If current leaves positive terminal, $p(t) < 0 ⇒$ **element delivers / generates energy**.

### 2. Comprehensive Taxonomy of Electrical Energy Sources

```
                                [ Electrical Sources ]
                                          |
                 +------------------------+------------------------+
                 |                                                 |
       [ Independent Sources ]                           [ Dependent (Controlled) Sources ]
       Terminal output fixed,                            Controlled by voltage or current
       independent of circuit                            elsewhere in network
                 |                                                 |
         +-------+-------+                                 +-------+-------+
         |               |                                 |       |       |       |
       [ V-Source ]   [ I-Source ]                       VCVS    VCCS    CCVS    CCCS
```

#### Practical (Real-World) vs Ideal Sources:
1. **Practical Voltage Source:** Modeled as an ideal independent EMF $V_s$ in series with an internal series resistance $R_{se}$:
   $$\mathbf{V_L = V_s - I_L · R_{se}}$$
   - As load current $I_L → ∞$, terminal voltage droops linearly.
   - For an **ideal voltage source**, internal resistance is zero: $R_{se} = 0 ⇒ V_L = V_s$ unconditionally.
2. **Practical Current Source:** Modeled as an ideal constant current generator $I_s$ in parallel with an internal shunt resistance $R_{sh}$:
   $$\mathbf{I_L = I_s - \frac{V_L}{R_{sh}}}$$
   - For an **ideal current source**, internal shunt resistance is infinite: $R_{sh} = ∞ ⇒ I_L = I_s$ unconditionally.

#### The Source Transformation Equivalence Theorem:
A practical voltage source $(V_s, R_{se})$ is electrically identical at external terminals to a practical current source $(I_s, R_{sh})$ if and only if:
$$\mathbf{I_s = \frac{V_s}{R_{se}}}    \text{and}    \mathbf{R_{sh} = R_{se}}$$

**Step 1 🚀: Total Equivalent Resistance**
$$R_{eq} = R₁ + R₂ + R₃ = 2 + 3 + 1 = \mathbf{6.0~\Omega}$$

**Step 2 ⚡: Circuit Current via Ohm's Law**
$$I = \frac{V}{R_{eq}} = \frac{12~\text{V}}{6~\Omega} = \mathbf{2.0~\text{Amperes}}$$

**Step 3 🎯: Voltage Drops**
$$V₁ = I R₁ = 2 \times 2 = \mathbf{4.0~\text{V}},    V₂ = I R₂ = 2 \times 3 = \mathbf{6.0~\text{V}},    V_3 = I R₃ = 2 \times 1 = \mathbf{2.0~\text{V}}$$
Sum verification: $4 + 6 + 2 = 12~\text{V}$.

**Step 1 🚀: Find the Load Current $I_L$**
$$I_L = \frac{V_L}{R_L} = \frac{18~\text{V}}{9~\Omega} = \mathbf{2.0~\text{A}}$$

**Step 2 ⚡: Calculate Internal Resistance $R_{se}$**
Internal voltage lost across electrolyte:
$$V_{\text{lost}} = E - V_L = 24 - 18 = 6.0~\text{V}$$
$$R_{se} = \frac{V_{\text{lost}}}{I_L} = \frac{6.0~\text{V}}{2.0~\text{A}} = \mathbf{3.0~\Omega}$$

**Step 3 🎯: Useful Power Delivered**
$$P_L = I_L^2 · R_L = (2.0)^2 \times 9 = \mathbf{36.0~\text{Watts}}$$

**Step 1 🚀: Convert Practical Voltage Source to Current Source**
- Ideal current: $I_{s1} = \frac{V_s}{R_{se}} = \frac{40~\text{V}}{5~\Omega} = 8.0~\text{A}$ (pointing up).
- Parallel resistance: $R_{sh1} = 5.0~\Omega$.

**Step 2 ⚡: Combine Parallel Current Sources and Parallel Resistors**
- Net current source: $I_{\text{total}} = 8.0~\text{A} + 6.0~\text{A} = \mathbf{14.0~\text{A}}$.
- Combined parallel resistance:
  $$R_p = 5~\Omega \parallel 10~\Omega = \frac{5 \times 10}{5 + 10} = \frac{50}{15} = \mathbf{3.33~\Omega}$$

**Step 3 🎯: Transform Back to Single Thevenin Voltage Source**
- $V_{th} = I_{\text{total}} \times R_p = 14.0 \times \frac{10}{3} = \mathbf{46.67~\text{V}}$.
- $R_{th} = R_p = 3.33~\Omega$.

**Step 4 🏁: Connect Load $R_L = 10~\Omega$ and Calculate $I_L$ and $P_L$**
$$I_L = \frac{V_{th}}{R_{th} + R_L} = \frac{46.67}{3.33 + 10} = \frac{46.67}{13.33} = \mathbf{3.50~\text{Amperes}}$$
$$P_L = I_L^2 · R_L = (3.50)^2 \times 10 = \mathbf{122.5~\text{Watts}}$$
