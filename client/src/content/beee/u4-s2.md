### 1. Binary Coded Decimal (BCD) & The +6 Correction Rule

#### 8421 BCD (Natural BCD) Encoding:
In 8421 BCD, each decimal digit ($0$ through $9$) is encoded as an independent 4-bit nibble using weights $8, 4, 2, 1$:
$$0_{10} = 0000_{\text{BCD}},    ...    9_{10} = 1001_{\text{BCD}}$$
- A 4-bit register has $2^4 = 16$ possible binary states ($0000_2$ to $1111_2$).
- The 6 code words from **$1010_2$ ($10_{10}$) through $1111_2$ ($15_{10}$) are ILLEGAL / FORBIDDEN states**!

---

### 2. Analytical Reason for the +6 Correction in BCD Addition

When two BCD digits are added using binary adders:
1. **Condition for Correction:** If the 4-bit binary sum exceeds $9$ ($> 1001_2$) OR generates an auxiliary carry out of the nibble ($C_{\text{out}} = 1$), the sum has stepped into or through the forbidden zone!
2. **The +6 Rule:** The difference between hexadecimal radix ($16$) and decimal radix ($10$) is $16 - 10 = 6$. Adding binary $0110_2$ ($+6$) skips directly past the 6 invalid states, forcing the correct decimal carry into the next higher nibble:
   $$\mathbf{\text{BCD Sum} = (\text{Binary Sum}) + 0110_2    (\text{if sum } > 9 \text{ or carry } = 1)}$$

---

### 3. Excess-3 (XS-3) Code & Self-Complementing Property

Excess-3 is an unweighted code obtained by adding binary $0011_2$ ($+3$) to each BCD digit:
$$\mathbf{\text{XS-3} = \text{BCD} + 0011_2}$$

#### The Self-Complementing Theorem:
> 🟢 **Theorem:** If an Excess-3 code word is bitwise inverted (taking 1's complement), the resulting code word is identical to the Excess-3 representation of the **9's complement** of the original decimal digit!
> $$\mathbf{\overline{\text{XS-3}(d)} = \text{XS-3}(9 - d)}$$
- **Engineering Advantage:** Allows digital arithmetic units to perform decimal subtraction using standard adders and simple inverter gates without complex borrow-propagation circuitry!

**Problem:**
Convert the decimal number $(47)_{10}$ into: (1) 8421 BCD code, (2) Excess-3 code.

---

**Step 1 🚀: 8421 BCD (Convert each digit individually into 4 bits)**
- $4 = 0100_2$
- $7 = 0111_2$
$$(47)_{10} = \mathbf{0100 ; 0111_{\text{BCD}}}$$

**Step 2 ⚡: Excess-3 Code (Add 3 to each digit)**
- For digit $4$: $4 + 3 = 7 = 0111_2$
- For digit $7$: $7 + 3 = 10 = 1010_2$
$$(47)_{10} = \mathbf{0111 ; 1010_{\text{XS-3}}}$$


🎯 $(47)_{10} = \mathbf{0100 ; 0111_{\text{BCD}}} = \mathbf{0111 ; 1010_{\text{XS-3}}}$.




**University Question (6 Marks):**
Perform the addition (38)_{BCD} + (45)_{BCD} using BCD arithmetic.

---

**Step 1 🚀: Binary Addition of Nibbles**
- 38 = 0011 ; 1000
- 45 = 0100 ; 0101
\begin{array}{r@{  }l}
  0011 & 1000 \\\n+ 0100 & 0101 \\\n\hline
  0111 & 1101    (7  and  13)
\end{array}

**Step 2 ⚡: Check for Illegal Nibbles (> 9)**
- Lower nibble is 1101_2 = 13 > 9 ⇒ **INVALID BCD!**
- Higher nibble is 0111_2 = 7 ≤ 9 ⇒ Valid.

**Step 3 🎯: Add +6 (0110_2) to Lower Nibble**
\begin{array}{r@{  }l}
  0111 & 1101 \\\n+ 0000 & 0110 \\\n\hline
  1000 & 0011    (8  and  3)
\end{array}
1000_2 = 8 and 0011_2 = 3 ⇒ (83)_(10). Matches 38 + 45 = 83!


🎯 BCD Sum: $\mathbf{1000 ; 0011_{\text{BCD}} = (83)_{10}}$.




**University Question (8 Marks):**
Demonstrate the self-complementing property of Excess-3 code by finding the 9's complement of (62)_(10) using bitwise complementation in Excess-3.

---

**Step 1 🚀: Represent (62)_(10) in Excess-3**
- 6 + 3 = 9 = 1001_2
- 2 + 3 = 5 = 0101_2
(62)_(10) = 1001 ; 0101XS-3

**Step 2 ⚡: Take Bitwise 1's Complement (Flip Every Bit)**
\overline{1001 ; 0101} = 0110 ; 1010_2

**Step 3 🎯: Decode Back to Decimal by Subtracting 3**
- Higher nibble: 0110_2 = 6 ⇒ 6 - 3 = 3
- Lower nibble: 1010_2 = 10 ⇒ 10 - 3 = 7
Decoded number is 37₁₀.

**Step 4 🏁: Mathematical Verification**
The 9's complement of 62 is:
99 - 62 = 37₁₀
The bitwise NOT gate directly executed decimal 9's complement subtraction with zero arithmetic!


🎯 Proved: Excess-3 bitwise flip yields $0110 ; 1010_{\text{XS-3}} = \mathbf{37_{10}}$, exactly the 9's complement of $62$.
