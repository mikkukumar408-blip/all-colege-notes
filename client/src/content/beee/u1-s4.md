### 1. Alternating Current (AC) Sinusoidal Waveform Theory

An alternating quantity is one whose magnitude and direction reverse periodically with time. The mathematical expression of a sinusoidal voltage wave is:
$$\mathbf{v(t) = V_m \sin(\omega t ± \phi)}$$
- **$V_m$ (Amplitude / Crest Value):** Peak positive excursion from zero.
- **$\omega = 2π f = \frac{2π}{T}$:** Angular frequency in radians per second ($\text{rad/s}$).
- **$f = 1/T$:** Cyclic frequency in Hertz ($\text{Hz}$ or cycles per second).
- **$\phi$:** Initial phase angle relative to time origin $t = 0$.

---

### 2. Analytical Derivation of RMS and Average Values

#### A. Root Mean Square (RMS) Value (Effective Value):
> 🟢 **Physical Definition:** The RMS value of an alternating current is defined as that value of steady direct current (DC) which, when flowing through a given resistor for a given time, produces the **exact same quantity of Joule heat** as the AC does in the same resistor over one full period $T$.

$$H_{dc} = I_{rms}^2 R T    \text{and}    H_{ac} = \int_0^T [i(t)]^2 R , dt$$
Equating:
$$\mathbf{I_{rms} = \sqrt{\frac{1}{T} \int_0^T [i(t)]^2 , dt}}$$

#### Mathematical Derivation for Pure Sinusoid $i(t) = I_m \sinθ$:
$$I_{rms}^2 = \frac{1}{2π} \int_0^{2π} I_m^2 \sin^2θ , dθ = \frac{I_m^2}{2π} \int_0^{2π} \frac{1 - \cos 2θ}{2} dθ = \frac{I_m^2}{4π} [θ]_0^{2π} = \frac{I_m^2}{4π} (2π) = \frac{I_m^2}{2}$$
$$\mathbf{I_{rms} = \frac{I_m}{\sqrt{2}} ≈ 0.7071 · I_m},      \mathbf{V_{rms} = \frac{V_m}{\sqrt{2}} ≈ 0.7071 · V_m}$$

#### B. Average Value ($I_{avg}$):
For a symmetrical wave, average over a full cycle is zero. Hence, the average value is defined over **one positive half-cycle**:
$$I_{avg} = \frac{1}{π} \int_0^π I_m \sinθ , dθ = \frac{I_m}{π} [-\cosθ]_0^π = \frac{I_m}{π} [1 - (-1)] = \mathbf{\frac{2 I_m}{π} ≈ 0.6366 · I_m}$$

---

### 3. Waveform Shape Characteristics

1. **Form Factor ($K_f$):** Ratio of RMS value to Average value:
   $$\mathbf{K_f = \frac{V_{rms}}{V_{avg}} = \frac{V_m / \sqrt{2}}{2 V_m / π} = \frac{π}{2\sqrt{2}} ≈ 1.11}$$
2. **Peak / Crest Factor ($K_p$):** Ratio of Peak value to RMS value:
   $$\mathbf{K_p = \frac{V_m}{V_{rms}} = \frac{V_m}{V_m / \sqrt{2}} = \sqrt{2} ≈ 1.414}$$

**Problem:**
A voltage wave is represented by $v(t) = 141.4 \sin(314 t)~\text{V}$. Find: (1) Peak voltage $V_m$, (2) RMS voltage $V_{rms}$, (3) Frequency $f$, (4) Time period $T$.

---

**Step 1 🚀: Compare with Standard Equation $v(t) = V_m \sin(\omega t)$**
$$V_m = \mathbf{141.4~\text{Volts}}$$

**Step 2 ⚡: Calculate RMS Voltage**
$$V_{rms} = \frac{V_m}{\sqrt{2}} = \frac{141.4}{1.414} = \mathbf{100.0~\text{Volts}}$$

**Step 3 🎯: Frequency & Time Period**
$$\omega = 2π f = 314 ⇒ f = \frac{314}{2π} = \frac{314}{6.283} = \mathbf{50.0~\text{Hz}}$$
$$T = \frac{1}{f} = \frac{1}{50} = \mathbf{0.020~\text{s} = 20~\text{ms}}$$


🎯 $V_m = 141.4~\text{V}$ | $V_{rms} = 100.0~\text{V}$ | Frequency $f = 50.0~\text{Hz}$ | Period $T = 20.0~\text{ms}$.




**University Question (6 Marks):**
Calculate the average value, form factor, and crest factor of an AC sinusoidal current of peak amplitude Iₘ = 20,A.

---

**Step 1 🚀: Average Value (Over Half Cycle)**
Iₐᵥg = (2 Iₘ / π) = (2 × 20 / π) = (40 / 3.1416) = 12.73,A

**Step 2 ⚡: RMS Value**
Iᵣₘₛ = (Iₘ / √(2)) = (20 / 1.4142) = 14.14,A

**Step 3 🎯: Form Factor (Kf) & Peak / Crest Factor (Kₚ)**
Kf = (Iᵣₘₛ / Iₐᵥg) = (14.14 / 12.73) = 1.11
Kₚ = (Iₘ / Iᵣₘₛ) = (20 / 14.14) = 1.414 = √(2)


🎯 $I_{avg} = 12.73~\text{A}$ | $I_{rms} = 14.14~\text{A}$ | Form Factor $K_f = 1.11$ | Crest Factor $K_p = 1.414$.




**University Question (10 Marks):**
Derive from first principles the RMS and Average values of a half-wave rectified sinusoidal voltage defined by:
$$v(\theta) = \begin{cases} V_m \sin\theta, & 0 \le \theta \le \pi \\ 0, & \pi \le \theta \le 2\pi \end{cases}$$
Hence find its Form Factor.

---

**Step 1 🚀: Average Value $V_{avg}$**
$$V_{avg} = \frac{1}{2\pi} \int_0^\pi V_m \sin\theta \, d\theta = \frac{V_m}{2\pi} \left[-\cos\theta\right]_0^\pi = \frac{V_m}{2\pi} (1 - (-1)) = \frac{V_m}{\pi} \approx \mathbf{0.318 \, V_m}$$

**Step 2 ⚡: RMS Value $V_{rms}$**
$$V_{rms}^2 = \frac{1}{2\pi} \int_0^\pi V_m^2 \sin^2\theta \, d\theta = \frac{V_m^2}{2\pi} \int_0^\pi \frac{1 - \cos 2\theta}{2} \, d\theta = \frac{V_m^2}{4\pi} [\theta]_0^\pi = \frac{V_m^2}{4}$$
$$V_{rms} = \sqrt{\frac{V_m^2}{4}} = \frac{V_m}{2} = \mathbf{0.50 \, V_m}$$

**Step 3 🎯: Form Factor ($K_f$)**
$$K_f = \frac{V_{rms}}{V_{avg}} = \frac{V_m / 2}{V_m / \pi} = \frac{\pi}{2} \approx \mathbf{1.57}$$


🎯 Half-Wave: $V_{avg} = \frac{V_m}{\pi}$ | $V_{rms} = \frac{V_m}{2}$ | Form Factor $K_f = 1.57$ (High distortion compared to pure sine 1.11).
