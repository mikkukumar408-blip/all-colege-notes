### 1. Electromagnetic Principles of the Single-Phase Transformer

A **transformer** is a static electromagnetic device that transfers electrical energy between two or more circuits via mutual magnetic induction at constant frequency.

#### Working Principle & Faraday's Law:
1. When sinusoidal voltage $v_1(t) = V_{m1}\sin(\omega t)$ is connected across primary winding of $N_1$ turns, an alternating magnetizing current flows, producing sinusoidal core flux:
   $$\phi(t) = \phi_m \sin(\omega t)    [\text{Weber, } \text{Wb}]$$
2. This common mutual flux links both primary and secondary windings through the high-permeability laminated ferromagnetic core.
3. By Faraday's Law of Induction, counter-EMFs are induced in both windings:
   $$e_1 = -N_1 \frac{d\phi}{dt},      e_2 = -N_2 \frac{d\phi}{dt}$$

---

### 2. Rigorous Derivation of the Transformer EMF Equation

Substitute sinusoidal flux $\phi(t) = \phi_m \sin(\omega t)$:
$$e_1 = -N_1 \frac{d}{dt}[\phi_m \sin(\omega t)] = -N_1 \omega \phi_m \cos(\omega t)$$
Using the trigonometric identity $-\cosθ = \sin(θ - 90^\circ)$:
$$e_1 = N_1 (2π f) \phi_m \sin(\omega t - 90^\circ)$$
The maximum (peak) induced EMF is:
$$E_{m1} = 2π f N_1 \phi_m$$
The Root Mean Square (RMS) value is:
$$E_1 = \frac{E_{m1}}{\sqrt{2}} = \frac{2π}{\sqrt{2}} f N_1 \phi_m = \sqrt{2}π f N_1 \phi_m$$
Since $\sqrt{2}π ≈ 1.4142 \times 3.1416 ≈ 4.44288$:
$$\mathbf{E_1 = 4.44 · f · N_1 · \phi_m}$$
Similarly, for the secondary winding:
$$\mathbf{E_2 = 4.44 · f · N_2 · \phi_m}$$

#### EMF per Turn (Core Invariant):
Dividing by the turn count yields the fundamental invariant of transformer design:
$$\mathbf{\frac{E_1}{N_1} = \frac{E_2}{N_2} = 4.44 · f · \phi_m = 4.44 · f · B_m · A_i}$$
where $B_m$ is maximum core flux density ($\text{Tesla}$) and $A_i$ is net iron cross-sectional area ($\text{m}^2$).

---

### 3. Transformation Ratio ($K$) & Impedance Reflection

$$\mathbf{K = \frac{V₂}{V₁} ≈ \frac{E_2}{E_1} = \frac{N_2}{N_1} = \frac{I₁}{I₂}}$$
- $K > 1 ⇒$ **Step-Up Transformer** ($V₂ > V₁, I₂ < I₁$).
- $K < 1 ⇒$ **Step-Down Transformer** ($V₂ < V₁, I₂ > I₁$).

#### Resistance and Reactance Referral Rules:
- Transferring secondary impedance to primary side:
  $$\mathbf{R₂' = \frac{R₂}{K^2}},      \mathbf{x₂' = \frac{x₂}{K^2}},      \mathbf{Z_{eq1} = R₁ + R₂' + j(x₁ + x₂')}$$
- Transferring primary impedance to secondary side:
  $$\mathbf{R₁'' = K^2 R₁},      \mathbf{x₁'' = K^2 x₁},      \mathbf{Z_{eq2} = R₂ + R₁'' + j(x₂ + x₁'')}$$

**University Question (8 Marks):**
A 2200 / 220,V, 50,Hz single-phase step-down transformer has 60 turns on the secondary winding.
Calculate: (1) Primary winding turns N₁, (2) Peak magnetic flux in the core φₘ, (3) Full-load primary current when secondary delivers 20,A.

---

**Step 1 🚀: Primary turns N₁**
(N₁ / N₂) = (V₁ / V₂) ⇒ (N₁ / 60) = \frac{2200}{220} = 10 ⇒ N₁ = 600,\,\text{turns}

**Step 2 ⚡: Peak magnetic flux φₘ via EMF equation**
E₂ = 4.44 · f · N₂ · φₘ ⇒ 220 = 4.44 × 50 × 60 × φₘ
220 = 13320 × φₘ ⇒ φₘ = \frac{220}{13320} = 0.0165,Wb = 16.5,\text(mWb)

**Step 3 🎯: Primary current I₁**
I₁ = I₂ · \left((N₂ / N₁)\right) = 20 × \left(\frac{60}{600}\right) = 2.0,Amperes


🎯 Primary Turns $N_1 = 600$ | Peak Flux $\phi_m = 16.5~\text{mWb}$ | Primary Current $I₁ = 2.0~\text{A}$.




**University Question (10 Marks):**
A 3300 / 230,V, 50,Hz single-phase transformer has a maximum flux density Bₘ = 1.2,Tesla in the core. The induced EMF per turn is 8.0,Volts.
Calculate: (1) Number of primary and secondary turns, (2) Net cross-sectional area of the core Aᵢ.

---

**Step 1 🚀: Primary and Secondary Turns**
EMF per turn = (E₁ / N₁) = (E₂ / N₂) = 8.0,V/turn
N₁ = (E₁ / EMF/turn) = \frac{3300}{8} = 412.5 ⇒ 413,\,\text{turns}
N₂ = (E₂ / EMF/turn) = \frac{230}{8} = 28.75 ⇒ 29,\,\text{turns}

**Step 2 ⚡: Peak Magnetic Flux φₘ**
EMF per turn = 4.44 · f · φₘ ⇒ 8.0 = 4.44 × 50 × φₘ
φₘ = (8.0 / 222) = 0.03604,Weber = 36.04,\text(mWb)

**Step 3 🎯: Core Cross-Sectional Area Aᵢ**
φₘ = Bₘ × Aᵢ ⇒ Aᵢ = (φₘ / Bₘ) = (0.03604 / 1.2) = 0.03003,m² = 300.3~\text{cm²}


🎯 $N_1 = 413~\text{turns}, N_2 = 29~\text{turns}$ | $\phi_m = 36.04~\text{mWb}$ | Core Area $A_i = 300.3~\text{cm}^2$.
