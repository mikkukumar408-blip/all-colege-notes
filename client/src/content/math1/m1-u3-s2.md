### 1. Homogeneous Functions & Euler's Theorem: Rigorous Analysis

> 🟢 **Definition:** A multivariable function $f(x, y)$ is **homogeneous of degree $n$** if for any scalar $t > 0$:
> $$\mathbf{f(t x, t y) = t^n f(x, y) \iff f(x, y) = x^n \, \phi\left(\frac{y}{x}\right)}$$

---

### 2. Euler's Theorem on Homogeneous Functions (First & Second Order)

> 🟢 **First-Order Euler's Theorem:** If $u = f(x, y)$ is a homogeneous function of $x$ and $y$ of degree $n$ with continuous partial derivatives, then:
> $$\mathbf{x \frac{\partial u}{\partial x} + y \frac{\partial u}{\partial y} = n \, u}$$

> 🟢 **Second-Order Euler's Formula:**
> $$\mathbf{x^2 \frac{\partial^2 u}{\partial x^2} + 2xy \frac{\partial^2 u}{\partial x \partial y} + y^2 \frac{\partial^2 u}{\partial y^2} = n(n - 1) u}$$

> 🔴 **Examiner's Composite Function Deduction:** If $z = f(u)$ is homogeneous of degree $n$ in $(x, y)$, then:
> 1. $x u_x + y u_y = n \frac{f(u)}{f'(u)} = g(u)$
> 2. $x^2 u_{xx} + 2xy u_{xy} + y^2 u_{yy} = g(u)\,[g'(u) - 1]$

**University Question (6 Marks - MMDU Question Paper):**
If $u = \sin^{-1}\left( \frac{x + 2y + 3z}{\sqrt{x^8 + y^8 + z^8}} \right)$, prove that $x u_x + y u_y + z u_z = -3 \tan u$.

---

**Step 1 🚀: Convert to Homogeneous Function $v = \sin u$**
$$v = \sin u = \frac{x + 2y + 3z}{\sqrt{x^8 + y^8 + z^8}}$$
Degree of numerator is $1$; degree of denominator is $\sqrt{t^8} = t^4$. Thus $v$ is homogeneous of degree $n = 1 - 4 = -3$.

**Step 2 ⚡: Apply 3-Variable Euler's Theorem to $v$**
$$x \frac{\partial v}{\partial x} + y \frac{\partial v}{\partial y} + z \frac{\partial v}{\partial z} = -3 v$$
Using $\frac{\partial v}{\partial x} = \cos u \frac{\partial u}{\partial x}$:
$$\cos u \left(x u_x + y u_y + z u_z\right) = -3 \sin u \implies x u_x + y u_y + z u_z = -3 \tan u$$

<div class="example-answer-box">
🎯 Result Proved: $\mathbf{x \frac{\partial u}{\partial x} + y \frac{\partial u}{\partial y} + z \frac{\partial u}{\partial z} = -3\tan u}$.
</div>

**University Question (6 Marks - MMDU Previous Paper):**
If $u = \tan^{-1}\left( \frac{x^3 + y^3}{x - y} \right)$, prove that $x^2 u_{xx} + 2xy u_{xy} + y^2 u_{yy} = \sin 2u\,(2\cos 2u - 1) = \sin 4u - \sin 2u$.

---

**Step 1 🚀: Define $z = \tan u$ (Degree $n = 3 - 1 = 2$)**
$$x z_x + y z_y = 2z \implies x \sec^2 u \, u_x + y \sec^2 u \, u_y = 2\tan u \implies x u_x + y u_y = \frac{2\tan u}{\sec^2 u} = \sin 2u = g(u)$$

**Step 2 ⚡: Second-Order Euler Identity**
$$x^2 u_{xx} + 2xy u_{xy} + y^2 u_{yy} = g(u)\,[g'(u) - 1] = \sin 2u\,(2\cos 2u - 1) = \sin 4u - \sin 2u$$

<div class="example-answer-box">
🎯 Second-Order Euler Identity Proved: $\mathbf{x^2 u_{xx} + 2xy u_{xy} + y^2 u_{yy} = \sin 2u (2\cos 2u - 1)}$.
</div>
