### 1. Multivariable Functions: Limits, Continuity & Partial Derivatives

#### A. Limit of a Function of Two Variables:
> 🟢 **Rigorous $\epsilon$-$\delta$ Definition:** We write $\lim_{(x, y) \to (a, b)} f(x, y) = L$ if for every $\epsilon > 0$, there exists a $\delta > 0$ such that:
> $$0 < \sqrt{(x - a)^2 + (y - b)^2} < \delta \implies |f(x, y) - L| < \epsilon$$

- **Path Independence Principle:** For a limit to exist in $\mathbb{R}^2$, the function must approach the **exact same value $L$ along EVERY conceivable path** approaching $(a, b)$.
- **Two-Path Non-Existence Test:** If $f(x, y)$ yields different values along paths $y = m x$ or $y = m x^2$ (i.e., limit depends on $m$), the limit **strictly DOES NOT EXIST**!

#### B. Continuity of $f(x, y)$:
A function $f(x, y)$ is continuous at $(a, b)$ if:
1. $f(a, b)$ is defined.
2. $\lim_{(x, y) \to (a, b)} f(x, y)$ exists.
3. $\lim_{(x, y) \to (a, b)} f(x, y) = f(a, b)$.

### 2. Partial Derivatives & Higher-Order Derivatives

$$\mathbf{\frac{\partial f}{\partial x} = f_x(x, y) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x, y) - f(x, y)}{\Delta x}}, \quad \mathbf{\frac{\partial f}{\partial y} = f_y(x, y) = \lim_{\Delta y \to 0} \frac{f(x, y + \Delta y) - f(x, y)}{\Delta y}}$$

> 🟢 **Clairaut's Symmetry Theorem:** If the mixed partial derivatives $f_{xy}$ and $f_{yx}$ are both **continuous** on an open region containing $(a, b)$, then:
> $$\mathbf{\frac{\partial^2 f}{\partial y \partial x} = \frac{\partial^2 f}{\partial x \partial y} \iff f_{yx} = f_{xy}}$$

**University Question (4 Marks):**
Evaluate whether $\lim_{(x, y) \to (0, 0)} \frac{x^2 y}{x^4 + y^2}$ exists.

---

**Step 1 🚀: Approach along straight line paths $y = mx$**
$$\lim_{x \to 0} \frac{x^2 (mx)}{x^4 + m^2 x^2} = \lim_{x \to 0} \frac{mx}{x^2 + m^2} = 0$$

**Step 2 ⚡: Approach along parabolic path $y = m x^2$**
$$\lim_{x \to 0} \frac{x^2 (m x^2)}{x^4 + m^2 x^4} = \frac{m}{1 + m^2}$$
Since the limit depends on $m$, the limit is **not unique** and **does NOT exist**.

<div class="example-answer-box">
🎯 By Path Test ($y = mx^2$), the limit **does NOT exist**.
</div>

**University Question (6 Marks - MMDU Question Paper):**
If $u = \ln(x^2 + y^2)$, prove that $u$ satisfies 2D Laplace's Equation: $\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0$.

---

**Step 1 🚀: First Partial Derivatives**
$$\frac{\partial u}{\partial x} = \frac{2x}{x^2 + y^2}, \quad \frac{\partial u}{\partial y} = \frac{2y}{x^2 + y^2}$$

**Step 2 ⚡: Second Partial Derivatives via Quotient Rule**
$$\frac{\partial^2 u}{\partial x^2} = \frac{2(x^2 + y^2) - 2x(2x)}{(x^2 + y^2)^2} = \frac{2y^2 - 2x^2}{(x^2 + y^2)^2}, \quad \frac{\partial^2 u}{\partial y^2} = \frac{2x^2 - 2y^2}{(x^2 + y^2)^2}$$

**Step 3 🎯: Sum the Second Derivatives**
$$\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = \frac{2y^2 - 2x^2 + 2x^2 - 2y^2}{(x^2 + y^2)^2} = 0$$

<div class="example-answer-box">
🎯 Proved: $\nabla^2 u = \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0$ ($u$ is Harmonic).
</div>
