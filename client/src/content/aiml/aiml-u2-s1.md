### 1. Formal Formulation of State Space Search Problems

In Artificial Intelligence, search is the systematic exploration of a graph of problem states to find an action sequence transitioning from an initial state to a goal state.

#### The Formal 5-Tuple Problem Formulation:
$$\mathbf{\mathcal{P} = \langle \mathcal{S}_0, \text{Actions}(s), \text{Result}(s, a), \text{Goal-Test}(s), c(s, a, s') \rangle}$$
1. **Initial State ($\mathcal{S}_0$):** The state from which the agent commences execution.
2. **Action Set ($\text{Actions}(s)$):** The set of legal moves executable from state $s$.
3. **Transition Model ($\text{Result}(s, a)$):** The state reached after applying action $a$ in state $s$.
4. **Goal Test ($\text{Goal-Test}(s)$):** A Boolean predicate determining whether state $s$ satisfies the problem goal.
5. **Path Cost ($c(s, a, s')$):** A step cost function assigning numeric cost to transition $(s \to {a} s')$.

### 2. Comprehensive Theoretical Comparison of Blind (Uninformed) Search

Uninformed search algorithms explore state space using only problem formulation mechanics, with no domain-specific knowledge about how close a state is to the goal.

| Search Algorithm | Data Structure | Complete? | Time Complexity | Space Complexity | Optimal? |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Breadth-First Search (BFS)** | FIFO Queue | **Yes** (if $b < ∞$) | $O(b^d)$ | $\mathbf{O(b^d)}$ *(Catastrophic!)* | **Yes** (if all step costs equal) |
| **Depth-First Search (DFS)** | LIFO Stack | **No** (fails in infinite paths) | $O(b^m)$ | $\mathbf{O(b cdot  m)}$ *(Linear, Excellent!)* | **No** (can return deep sub-optimal path) |
| **Uniform-Cost Search (UCS / Dijkstra)** | Min-Priority Queue on $g(n)$ | **Yes** (if step cost $\epsilon > 0$) | $O(b^{1 + \lfloor C^* / \epsilon \rfloor})$ | $O(b^{1 + \lfloor C^* / \epsilon \rfloor})$ | **Yes** (for arbitrary positive costs) |
| **Depth-Limited Search (DLS)** | LIFO Stack (limit $L$) | **No** (if $d > L$) | $O(b^L)$ | $\mathbf{O(b cdot  L)}$ | **No** |
| **Iterative Deepening Search (IDS)** | LIFO Stack (incremental $L$) | **Yes** (if $b < ∞$) | $O(b^d)$ | $\mathbf{O(b cdot  d)}$ *(The Gold Standard!)* | **Yes** (if step costs equal) |

- **Notation:** $b$ = branching factor, $d$ = depth of shallowest goal, $m$ = maximum search tree depth, $C^*$ = optimal path cost.

---

### 3. Why Iterative Deepening Search (IDS) Dominates in Blind Search

Students intuitively assume that re-running DFS from depth $0$ to $d$ wastes massive computational time.
However, in a search tree with branching factor $b$, the vast majority of nodes reside in the **bottom leaf layer**:
$$\text{Total nodes generated by IDS} = (d)b^1 + (d-1)b^2 + ... + (1)b^d approx  O(b^d)$$
For $b = 10$ and $d = 5$:
- BFS generates: $10^5 = 100{,}000$ nodes and requires storing all $100{,}000$ in RAM!
- IDS generates: $123{,}450$ nodes (only $23%$ overhead) but requires storing only $\mathbf{b cdot  d = 50\text{ nodes}}$ in RAM!
- **Conclusion:** IDS combines the complete, optimal path guarantee of BFS with the modest $O(bd)$ linear memory profile of DFS.

**Problem:**
A balanced binary search tree has depth $d = 3$ (root at depth 0, 8 leaves at depth 3). A target goal node is located at the leftmost position of depth 3. Find the number of nodes expanded by: (1) Breadth-First Search (BFS), (2) Depth-First Search (DFS).

---

**Step 1 🚀: BFS Node Expansions**
BFS explores level by level:
- Depth 0: 1 node (Root)
- Depth 1: 2 nodes
- Depth 2: 4 nodes
- Depth 3: Goal is the 1st node inspected.
$$\text{Total BFS expansions} = 1 + 2 + 4 + 1 = \mathbf{8,\text{nodes}}$$

**Step 2 ⚡: DFS Node Expansions**
DFS dives directly down the leftmost child pointer:
- Root $\to $ Left child (depth 1) $\to $ Left grandchild (depth 2) $\to $ Goal node (depth 3).
$$\text{Total DFS expansions} = \mathbf{4,\text{nodes}}$$


🎯 BFS Expands: 8 nodes | DFS Expands: **4 nodes** (DFS reaches leftmost branch instantly!).




**University Question (8 Marks):**
Find the lowest-cost path from S to G using Uniform-Cost Search (cheapest cumulative cost first):
- S → A (1), S → B (5)
- A → B (2), A → C (4)
- B → G (4), C → G (1)

---

**Step 1 🚀: Priority Queue Initialization**
- Priority Queue (PQ): [(S, g=0)]

**Step 2 ⚡: Step-by-Step Expansion**
1. **Pop S (g=0):**
   - Add A: g = 0 + 1 = 1
   - Add B: g = 0 + 5 = 5
   - PQ: [(A, 1), (B, 5)]
2. **Pop A (g=1):**
   - Path to B via A: g = 1 + 2 = 3 *(Cheaper than direct path g=5! Update B)*
   - Path to C: g = 1 + 4 = 5
   - PQ: [(B, 3), (C, 5)]
3. **Pop B (g=3):**
   - Path to G: g = 3 + 4 = 7
   - PQ: [(C, 5), (G, 7)]
4. **Pop C (g=5):**
   - Path to G: g = 5 + 1 = 6 *(Cheaper than 7! Update G)*
   - PQ: [(G, 6)]
5. **Pop G (g=6):** Goal reached!

**Step 3 🎯: Optimal Path Recovery**
S → A → C → G    with total cost  6


🎯 Optimal UCS Path: $\mathbf{S \to  A \to  C \to  G}$ with minimum cost = **6**.




**University Question (10 Marks):**
A state space graph has uniform branching factor b = 10 and goal depth d = 6. Each search node requires 256,\,\text{bytes} of memory in RAM.
Calculate:
1. The maximum memory consumed by BFS at depth d = 6.
2. The maximum memory consumed by DFS with maximum tree depth m = 10.
3. Explain why Iterative Deepening Search (IDS) achieves the optimal combination.

---

**Step 1 🚀: BFS Memory Consumption at d = 6**
BFS must retain all generated nodes in the frontier queue at level d:
NBFS = bᵈ = 10⁶ = 1(,)000(,)000,
odes
RAM = 10⁶ × 256,\,\text{bytes} = 256,MB
*(If depth were d=8, BFS would require 25.6,GB, and at d=10, 2.56,TB—crashing ordinary machines!).*

**Step 2 ⚡: DFS Memory Consumption (m = 10)**
DFS only stores the current branch in the stack:
NDFS = b · m = 10 × 10 = 100,
odes
RAM = 100 × 256,\,\text{bytes} = 25.6,KB!
DFS uses **10,000 times less memory** than BFS!

**Step 3 🎯: Why Iterative Deepening Search (IDS) Wins**
- IDS runs DFS with depth limit L = 0, 1, 2, ..., d.
- It guarantees finding the **optimal shortest path** (like BFS) while keeping memory linear: O(b · d) (like DFS).


🎯 BFS RAM = **256 MB** | DFS RAM = **25.6 KB** | IDS combines BFS optimality with DFS $O(bd)$ linear memory.
