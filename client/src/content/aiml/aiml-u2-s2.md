### 1. In-Depth Theory of Informed (Heuristic) Search & The A* Algorithm

Informed search exploits domain-specific heuristic functions to guide search toward the most promising regions of the state space.

#### The Heuristic Function $h(n)$:
> 🟢 **Definition:** A **Heuristic Function** $h(n): \mathcal{S} \to  \mathbb{R}_{≥ 0}$ estimates the cheapest path cost from node $n$ to the closest goal state.
> For any goal node $G$, $h(G) = 0$.

---

### 2. The A* Evaluation Function & Algorithm Mechanics

The A* search algorithm evaluates nodes using the combined evaluation function:
$$\mathbf{f(n) = g(n) + h(n)}$$
- **$g(n)$ (Past Cost):** The exact, true path cost incurred so far from the start node $s_0$ to node $n$.
- **$h(n)$ (Future Estimate):** The estimated remaining cost from node $n$ to the goal.
- **$f(n)$ (Total Estimated Cost):** The estimated total cost of the cheapest solution passing through node $n$.

---

### 3. Proof of Optimality of A* Search (Admissibility & Consistency)

#### A. Admissible Heuristic (Tree Search Optimality):
> 🟢 **Definition:** A heuristic $h(n)$ is **admissible** (optimistic) if it never overestimates the true remaining cost to reach the goal:
> $$\mathbf{0 ≤ h(n) ≤ h^*(n)}    (\forall n)$$
> where $h^*(n)$ is the true, optimal cost from $n$ to the goal.

#### Formal Proof of A* Tree-Search Optimality:
Let $G_2$ be a sub-optimal goal node ($g(G_2) > C^*$), and let $G^*$ be an optimal goal node ($g(G^*) = C^*$).
Suppose by contradiction that A* selects $G_2$ from the priority queue before $G^*$.
Since $G_2$ is a goal node, $h(G_2) = 0 ⇒ f(G_2) = g(G_2) > C^*$.
Consider some open ancestor node $n$ on the optimal path to $G^*$:
$$f(n) = g(n) + h(n) ≤ g(n) + h^*(n) = C^*    (\text{by admissibility})$$
Therefore:
$$f(n) ≤ C^* < f(G_2)$$
Since the priority queue always selects the node with the minimum $f$-value, A* must select node $n$ before $G_2$. By mathematical induction along the optimal path, A* will expand $G^*$ and terminate with the optimal solution! $\blacksquare$

#### B. Consistent / Monotonic Heuristic (Graph Search Optimality):
> 🟢 **Definition:** A heuristic is **consistent (monotonic)** if for every node $n$ and every successor $n'$ generated by action $a$:
> $$\mathbf{h(n) ≤ c(n, a, n') + h(n')}$$
> (This is the **Triangle Inequality** in metric spaces).

- **Theorem:** If $h(n)$ is consistent, then:
  1. $f(n)$ is non-decreasing along any path: $f(n') ≥ f(n)$.
  2. Whenever A* expands a node $n$, the optimal path to $n$ is already found ($g(n) = g^*(n)$). Node reopening is never required!

**Problem:**
In an A* search, an agent is at node $N$. The path cost accumulated from the start node is $g(N) = 14,\text{km}$. The straight-line distance heuristic to the destination is $h(N) = 22,\text{km}$.
Calculate the estimated total trip cost $f(N)$ and explain what happens if $h(N) = 0$.

---

**Step 1 🚀: Evaluation Function**
$$f(N) = g(N) + h(N) = 14 + 22 = \mathbf{36.0,\text{km}}$$

**Step 2 ⚡: Special Case $h(N) = 0$**
If heuristic is zero everywhere: $f(N) = g(N) + 0 = g(N)$.
A* search degenerates identically into **Uniform-Cost Search (Dijkstra's Algorithm)**!


🎯 $f(N) = 36.0,\text{km}$ | When $h(n)=0$, A* becomes standard Uniform-Cost Search.




**University Question (8 Marks):**
For an 8-puzzle game:
- Heuristic h₁: Number of misplaced tiles.
- Heuristic h₂: Total Manhattan distance (sum of horizontal and vertical distances to goal squares).
1. Prove why both heuristics are **admissible**.
2. Determine which heuristic dominates the other.

---

**Step 1 🚀: Proof of Admissibility for h₁**
Each misplaced tile must be moved at least once to reach its goal position. Therefore, h₁(n) ≤ h^*(n). Since it never overestimates, **h₁ is admissible**.

**Step 2 ⚡: Proof of Admissibility for h₂**
In the true game, tiles block each other and must move along grid squares. The Manhattan distance is the theoretical minimum distance if other tiles did not block the way. Thus, h₂(n) ≤ h^*(n). Therefore, **h₂ is admissible**.

**Step 3 🎯: Dominance Relation**
A single tile move can decrease its Manhattan distance by at most 1. Hence, the number of moves needed is always at least the Manhattan distance:
h₂(n) ≥ h₁(n)    ∀ n
Since h₂(n) ≥ h₁(n) for all states and both are admissible, **h₂ strictly dominates h₁**. A* using Manhattan distance expands fewer or equal nodes!


🎯 Both are admissible | $h_2$ (Manhattan) **dominates** $h_1$ (Misplaced tiles) $⇒$ $h_2$ explores a smaller search space.




**Guaranteed 14-Mark University Numerical:**
Find the shortest path from Start ($S$) to Goal ($G$) using A* Graph Search:
- Edges: $S \to  A (2)$, $S \to  B (4)$, $A \to  C (4)$, $A \to  D (7)$, $B \to  D (3)$, $B \to  E (5)$, $C \to  G (5)$, $D \to  G (3)$, $E \to  G (4)$.
- Heuristics: $h(S)=8, h(A)=6, h(B)=5, h(C)=4, h(D)=2, h(E)=3, h(G)=0$.

---

**Step 1 🚀: Start at $S$**
- Open List: $[S(g=0, h=8, f=8)]$
- Expand $S$:
  - Successor $A$: $g = 2, f = 2 + 6 = 8$
  - Successor $B$: $g = 4, f = 4 + 5 = 9$
- Open List: $[A(f=8), B(f=9)]$

**Step 2 ⚡: Expand cheapest node $A$ ($f=8$)**
- From $A$:
  - Successor $C$: $g = 2 + 4 = 6, f = 6 + 4 = 10$
  - Successor $D$: $g = 2 + 7 = 9, f = 9 + 2 = 11$
- Open List: $[B(f=9), C(f=10), D(f=11)]$

**Step 3 🎯: Expand cheapest node $B$ ($f=9$)**
- From $B$:
  - Successor $D$: $g = 4 + 3 = 7, f = 7 + 2 = 9$ *(Cheaper than via A! Update parent to B)*
  - Successor $E$: $g = 4 + 5 = 9, f = 9 + 3 = 12$
- Open List: $[D(f=9), C(f=10), E(f=12)]$

**Step 4 🏁: Expand cheapest node $D$ ($f=9$) & Reach $G$**
- From $D$:
  - Successor $G$: $g = 7 + 3 = 10, f = 10 + 0 = 10$
- Open List: $[C(f=10), G(f=10), E(f=12)]$
- Expand $G(f=10)$: Goal reached!
Trace parents: $G \leftarrow D \leftarrow B \leftarrow S$.


🎯 Optimal Path: $\mathbf{S \to  B \to  D \to  G}$ with minimum path cost = **10**.
