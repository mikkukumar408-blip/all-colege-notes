<example level="easy" title="Question 4 (1 Mark): Space Complexity Bottleneck of Breadth-First Search (BFS)">
**Question:**  
Why does Breadth-First Search exhaust physical RAM long before it exhausts allowable CPU compute time?

> 📊 **Question Schematic / State Specification:**
```
Question Frontier Expansion Diagram: Level 0: 1 node | Level 1: b nodes | Level d: bᵈ nodes kept simultaneously in memory.
```

---

**Step-by-Step Solution:**

> ⚡ **Solution Analytical Derivation & Schematic:**
```
Solution Memory Consumption Metric:

        `Space Complexity = O(bᵈ)`. For branching factor b=10, depth d=10: `10¹⁰ × 100  bytes ≈ 1  Terabyte RAM`!
```

BFS must store the entire active search frontier at level d in its FIFO queue. Because memory grows exponentially as O(bᵈ), physical RAM saturates in minutes, whereas DFS consumes only linear memory O(b·m).

<example level="easy" title="Question 5 (1 Mark): Mathematical Condition for A* Heuristic Consistency">
**Question:**  
State the triangle inequality formulation required for a heuristic to be consistent (monotonic).

> 📊 **Question Schematic / State Specification:**
```
Question Node Graph Triangle: Node n ➔ [Actual Edge Cost c(n, a, n')] ➔ Successor n' ➔ [Heuristic h(n')] ➔ Goal.
```

---

**Step-by-Step Solution:**

> ⚡ **Solution Analytical Derivation & Schematic:**
```
Solution Consistency Triangle Inequality:

        `h(n) ≤ c(n, a, n') + h(n')` for all successors n' generated by action a.
```

Consistency ensures that the estimated cost f(n) along any path never decreases: f(n') = g(n') + h(n') ≥ g(n) + h(n) = f(n). This guarantees that the first time A* visits any state, it has discovered its optimal path.

<example level="easy" title="Question 6 (1 Mark): The Purpose of Skolemization in FOPC">
**Question:**  
Why cannot existential quantifiers simply be dropped like universal quantifiers during CNF conversion?

> 📊 **Question Schematic / State Specification:**
```
Question Scope Trap: ∀x ∃y Likes(x, y) [Each x likes someone different] vs ∃y ∀x Likes(x, y) [Someone is liked by everyone].
```

---

**Step-by-Step Solution:**

> ⚡ **Solution Analytical Derivation & Schematic:**
```
Solution Skolem Function Substitution Model:

        `∃y bound within ∀x scope ⟹ Substitute y with Skolem Function f(x): ∀x Likes(x, f(x))`.
```

Existential quantifiers assert existence of an entity that depends upon enclosing universal quantifiers. Dropping ∃y naively turns it into a universal variable, destroying semantic validity. It must be replaced with a Skolem constant or function.

<example level="medium" title="Question 14 (2 Marks): Resolution Proof by Contradiction in Propositional Logic">
**Question:**  
Given Knowledge Base KB = {A &or; B, &not;B &or; C, &not;C}, prove statement A using Resolution Refutation.

> 📊 **Question Schematic / State Specification:**
```
Question Initial Clause Pool: Clause 1: (A &or; B) | Clause 2: (&not;B &or; C) | Clause 3: (&not;C) | Target Goal: A.
```

---

**Step-by-Step Solution:**

> ⚡ **Solution Analytical Derivation & Schematic:**
```
Solution Resolution Refutation Tree:

        `Negate Goal: C4 = (&not;A)`

        `Resolve C2 (&not;B &or; C) with C3 (&not;C) ⟹ C5 = (&not;B)`

        `Resolve C1 (A &or; B) with C5 (&not;B) ⟹ C6 = (A)`

        `Resolve C6 (A) with C4 (&not;A) ⟹ &square; (EMPTY CLAUSE / CONTRADICTION!)`
```

Derivation of the empty clause &square; proves that negating A leads to a logical contradiction with the KB. Therefore, statement A is proven true by refutation.

<example level="hard" title="Question 18 (4 Marks): Step-by-Step Execution of A* Search on a Weighted Graph">
**Question:**  
Trace A* search from Start node S to Goal node G. Edge costs: S-A=2, S-B=4, A-C=3, A-D=5, B-D=2, C-G=4, D-G=3. Heuristics: h(S)=7, h(A)=5, h(B)=4, h(C)=3, h(D)=2, h(G)=0.

> 📊 **Question Schematic / State Specification:**
```
Question Graph Topology: S ➔ A (cost 2) & B (cost 4); A ➔ C (cost 3) & D (cost 5); B ➔ D (cost 2); C ➔ G (cost 4); D ➔ G (cost 3).
```

---

**Step-by-Step Solution:**

> ⚡ **Solution Analytical Derivation & Schematic:**
```
Solution Priority Queue Frontier Execution Trace:

        `Step 1: Init Queue = [S(f=0+7=7)] ➔ Pop S`

        `Expand S ➔ A: g=2, f=2+5=7; B: g=4, f=4+4=8. Queue = [A(f=7), B(f=8)] ➔ Pop A`

        `Expand A ➔ C: g=2+3=5, f=5+3=8; D: g=2+5=7, f=7+2=9. Queue = [B(f=8), C(f=8), D(f=9)] ➔ Pop B`

        `Expand B ➔ D: g=4+2=6, f=6+2=8 (Cheaper D path found!). Queue = [C(f=8), D(f=8)] ➔ Pop C`

        `Expand C ➔ G: g=5+4=9, f=9+0=9. Queue = [D(f=8), G(f=9)] ➔ Pop D`

        `Expand D ➔ G: g=6+3=9, f=9+0=9. Queue = [G(f=9)] ➔ Pop G (GOAL REACHED!)`
```

**Optimal Path Found:** `S ➔ B ➔ D ➔ G` with total optimal path cost = `4 + 2 + 3 = 9`. (Path S-A-C-G also has cost 9; A* correctly guarantees discovery of optimal cost).

<example level="hard" title="Question 22 (6 Marks): Full Propositional and Predicate Logic Formal Proof Pipeline">
**Question:**  
Convert the following facts to FOPC, convert to CNF, and prove using Resolution: (1) "Marcus was a man", (2) "Marcus was a Pompeian", (3) "All Pompeians were Romans", (4) "Caesar was a ruler", (5) "All Romans were either loyal to Caesar or hated him", (6) "Everyone is loyal to someone", (7) "Men only cause trouble to people they do not like". Prove: "Marcus hated Caesar".

> 📊 **Question Schematic / State Specification:**
```
Question Knowledge Base Clauses: Man(Marcus), Pompeian(Marcus), ∀x Pompeian(x) ⟹ Roman(x), ∀x Roman(x) ⟹ (Loyal(x, Caesar) &or; Hate(x, Caesar)).
```

---

**Step-by-Step Solution:**

> ⚡ **Solution Analytical Derivation & Schematic:**
```
Solution Full CNF & Resolution Pipeline:

        `C1: Man(Marcus)`

        `C2: Pompeian(Marcus)`

        `C3: &not;Pompeian(x) &or; Roman(x)`

        `C4: &not;Roman(y) &or; Loyal(y, Caesar) &or; Hate(y, Caesar)`

        `C5: &not;Loyal(Marcus, Caesar)  [Asserted from context facts]`

        `Negate Target: C6: &not;Hate(Marcus, Caesar)`

        `Resolve C2 with C3 (subst (x/Marcus)) ⟹ C7: Roman(Marcus)`

        `Resolve C7 with C4 (subst (y/Marcus)) ⟹ C8: Loyal(Marcus, Caesar) &or; Hate(Marcus, Caesar)`

        `Resolve C8 with C5 ⟹ C9: Hate(Marcus, Caesar)`

        `Resolve C9 with C6 ⟹ &square; (EMPTY CLAUSE DERIVED!)`
```

The successful unification and resolution to the empty clause &square; provides rigorous, sound proof that **Marcus hated Caesar**.
